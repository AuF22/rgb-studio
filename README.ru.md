# RGB Studio

**Простое и понятное приложение для управления RGB-подсветкой компьютера на Windows.**
Работает на движке [OpenRGB](https://openrgb.org). Движок уже встроен, отдельно ничего ставить не нужно.

> [!NOTE]
> **RGB Studio — независимый интерфейс поверх [OpenRGB](https://openrgb.org).** Всю сложную часть делает OpenRGB:
> драйверы и протоколы для сотен материнских плат, модулей памяти, видеокарт, клавиатур и вентиляторов.
> RGB Studio добавляет к нему понятный интерфейс. С проектом OpenRGB приложение не связано.
>
> **Приложение спроектировал и написал [Claude](https://claude.com/claude-code)**, ИИ от Anthropic,
> в Claude Code по просьбе [@AuF22](https://github.com/AuF22).

## Возможности

- **Вся подсветка в одном месте:** материнская плата, память, видеокарта, клавиатура, мышь, ARGB-вентиляторы и ленты. Работает всё, что поддерживает OpenRGB.
- **Живой предпросмотр** каждого светодиода. Вентиляторы нарисованы кольцами, клавиатура сеткой клавиш.
- **Каждое устройство и каждая зона настраиваются отдельно:** свой эффект на каждом ARGB-разъёме, каждой зоне видеокарты, каждой планке памяти.
- **Эффекты:** статичный, градиент, дыхание, смена цветов, радуга, радужная волна, цветная волна, комета,
  **«Звёздная ночь»** (как в Armoury Crate), выключить.
- **Клавиатура:** клавиши загораются под пальцами или пускают волну по клавиатуре.
- **Музыка:** спектр, пульс по битам и индикатор уровня. Подсветка реагирует на звук, который играет на компьютере.
- **Повтор экрана (ambilight):** каждое устройство или зона повторяет свою часть экрана. Области задаются в наглядном редакторе.
- **Подбор числа светодиодов** для ARGB-разъёмов: ползунок зажигает ровно N светодиодов, и видно, где кончается вентилятор или лента.
- **Встроенные режимы устройств.** Они хранятся в самом устройстве и работают даже при закрытом приложении.
- **Профили**, общая яркость, автозапуск с Windows в трей. Последняя подсветка восстанавливается после перезапуска.

## Установка

1. Скачайте **`RGB-Studio-Setup-x.y.z.exe`** из раздела [Releases](https://github.com/AuF22/rgb-studio/releases/latest).
2. Запустите. В установщике можно включить автозапуск с Windows и установку драйвера **PawnIO**
   (он нужен для оперативной памяти и части материнских плат).
3. Откройте RGB Studio и подтвердите запрос прав администратора.

Есть и **портативный zip**: распакуйте в любую папку и запустите `RGB Studio.exe`.

> [!TIP]
> Windows SmartScreen может предупредить о неизвестном издателе, потому что у приложения нет цифровой подписи.
> Нажмите **Подробнее → Выполнить в любом случае**. Или [соберите его сами](#сборка-из-исходников).

### Первые шаги

- **Зачем права администратора?** Память и многие материнские платы управляются через шину SMBus,
  а Windows даёт к ней доступ только администраторам. Автозапуск сделан через Планировщик заданий,
  поэтому при входе в систему запрос UAC не появляется.
- **ARGB-вентиляторы или ленты не горят?** ARGB-светодиоды не сообщают, сколько их подключено,
  ни RGB Studio, ни любой другой программе. Под разъёмом в предпросмотре нажмите **«Подобрать»** и двигайте ползунок,
  пока красный огонёк не окажется на последнем светодиоде. Пока число не задано, на каждом разъёме стоит 40.
- **Нет какого-то устройства?** RGB Studio видит то же, что поддерживает OpenRGB.
  Проверьте [список устройств OpenRGB](https://openrgb.org/devices.html). Например, геймпады с протоколом Xbox 360
  не умеют управлять подсветкой.

## Приватность

Всё работает локально. Интерфейс доступен только на `127.0.0.1`.
Клавиатурные эффекты используют низкоуровневый перехват клавиатуры и только пока такой эффект включён. В памяти
секунды две хранится лишь название нажатых клавиш. Звук и изображение экрана анализируются на лету
и никуда не сохраняются и не отправляются.

## Сборка из исходников

Нужны Windows 10/11 x64 и Python 3.12 или новее
(для установщика ещё [Inno Setup 6](https://jrsoftware.org/isinfo.php)).

```bash
py -m pip install -r requirements.txt
```

```bash
py tools/fetch_engine.py
```

```bash
py app.py
```

`fetch_engine.py` скачивает OpenRGB 1.1 и установщик PawnIO из их официальных релизов
и проверяет контрольные суммы SHA-256. Полезные флаги `app.py`: `--demo` (виртуальные устройства),
`--minimized` (только трей), `--no-window` (только сервер на http://127.0.0.1:6750).

Собрать exe, портативный zip и установщик в папку `release/`:

```bash
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

## Как устроено

```
 ┌───────────────┐  HTTP (localhost)  ┌───────────────────────────┐  OpenRGB SDK (TCP 6742)  ┌──────────────┐
 │ Интерфейс     │ ─────────────────▶ │ RGB Studio (Python)       │ ───────────────────────▶ │ OpenRGB 1.1  │──▶ устройства
 │ (окно Edge    │ ◀───────────────── │ эффекты 30 кадр/с, звук,  │                          │ (без окна,   │
 │ как программа)│  кадры светодиодов │ экран, клавиши, профили   │                          │  встроенный) │
 └───────────────┘                    └───────────────────────────┘                          └──────────────┘
```

| Путь | Назначение |
|---|---|
| `app.py` | Flask-сервер и REST API, окно приложения, трей, автозапуск, единственный экземпляр |
| `openrgb_runtime.py` | Запуск встроенного OpenRGB без окна и привязка его к приложению; права администратора, PawnIO |
| `rgb_backend.py` | Устройства через OpenRGB SDK и виртуальные демо-устройства |
| `effects.py` | Движок эффектов: отдельно для устройств и зон, ~30 кадров/с |
| `sources.py` | Живые источники: звук (WASAPI loopback), захват экрана, клавиатура |
| `static/` | Интерфейс (HTML, CSS и JS без фреймворков) |
| `installer/` | Сценарий Inno Setup |
| `tools/` | Загрузка движка, иконка, скриншоты, сборка |

Настройки и профили хранятся в `%APPDATA%\RGBStudio`.
