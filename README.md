# RGB Studio

Простое приложение для управления подсветкой ПК. Ставить OpenRGB не нужно:
движок [OpenRGB](https://openrgb.org) уже лежит внутри и запускается скрыто, без окон и значков.

## Запуск готовой сборки

Распакуйте `RGB-Studio-win64.zip` в любую папку и запустите `RGB Studio.exe`.
Windows спросит разрешение на запуск от администратора: без этих прав не будут видны оперативная память
и часть устройств, подключённых к шине SMBus.

- Закрытие окна не выключает эффекты: приложение остаётся в трее (значок у часов).
  «Выход» в меню значка закрывает его полностью.
- Если не видна оперативная память, нажмите «Установить драйвер» на жёлтой плашке.
  Драйвер PawnIO ставится один раз.
- ARGB-разъёмы на материнской плате изначально показывают 0 светодиодов.
  Нажмите «Указать число LED» и введите, сколько светодиодов в подключённых вентиляторах или ленте.
- В настройках можно включить «Запускать вместе с Windows».

## Сборка из исходников

```bash
py -m pip install -r requirements.txt
```

```bash
py tools/fetch_engine.py
```

```bash
py app.py
```

Сборка exe и zip в папку `dist\`:

```bash
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

Флаги `app.py`: `--minimized` (только трей), `--no-window` (только сервер на http://127.0.0.1:6750),
`--demo` (виртуальные устройства), `--port N`.

## Что умеет

- Список устройств с живым предпросмотром каждого светодиода.
- Каждое устройство и каждую его зону можно настроить отдельно: нажмите «▸» у устройства, чтобы увидеть зоны.
- Эффекты: статичный, градиент, дыхание, смена цветов, радуга, радужная волна, цветная волна, комета,
  звёздная ночь, выключить.
- Клавиатура: «Нажатия» (клавиша загорается под пальцем) и «Волна от нажатия».
  Нажатия не записываются и никуда не отправляются: в памяти держится только название клавиши на пару секунд.
- Музыка: спектр, пульс по битам, индикатор уровня — по звуку, который играет на компьютере.
- Повтор экрана: каждому устройству или зоне можно обвести свою часть монитора.
- Подбор числа светодиодов на ARGB-разъёмах: ползунок зажигает ровно столько светодиодов, сколько выставлено.
- До 6 цветов в палитре, скорость, яркость, направление; общая яркость одним ползунком.
- Встроенные (аппаратные) режимы устройства — работают и при закрытом приложении.
- Профили, профиль при запуске, автозапуск с Windows (в трей).

## Как устроено

| Файл | Что делает |
|---|---|
| `app.py` | Flask-сервер с REST API, окно (Edge/Chrome в режиме приложения), трей, автозапуск |
| `openrgb_runtime.py` | Скрытый запуск встроенного OpenRGB, права администратора, установка PawnIO |
| `rgb_backend.py` | Работа с устройствами через OpenRGB SDK и демо-устройства |
| `effects.py` | Эффекты, ~30 кадров/с; отдельные настройки для зон |
| `sources.py` | Звук (WASAPI loopback), захват экрана, нажатия клавиш |
| `static/` | Интерфейс |
| `tools/` | Загрузка движка, иконка, сборка |

Настройки и профили хранятся в `%APPDATA%\RGBStudio`.

## Сторонние компоненты

- OpenRGB 1.1 — GPL-2.0, исходники: https://codeberg.org/OpenRGB/OpenRGB.
  Используется без изменений, как отдельный процесс, через сетевой протокол SDK.
- PawnIO 2.2.0 — https://pawnio.eu, драйвер доступа к SMBus.

Подробности в `openrgb/THIRD_PARTY_NOTICE.txt`.
