# RGB Studio

Простое приложение для управления подсветкой ПК поверх [OpenRGB](https://openrgb.org).
OpenRGB отвечает за драйверы и связь с железом, RGB Studio — за понятный интерфейс.

## Запуск

1. Установите OpenRGB и запустите его **от имени администратора**.
2. Во вкладке **SDK Server** нажмите **Start Server** (порт 6742).
   Чтобы не делать это каждый раз: *Settings → Start at login*, *Start server*, *Start minimized*.
3. Дважды кликните `RGB Studio.bat` — откроется окно приложения.

Или из терминала:

```bash
py app.py
```

Флаги: `--no-window` (только сервер, адрес http://127.0.0.1:6750), `--demo` (без OpenRGB), `--port N`.

Если OpenRGB не запущен, приложение переходит в **демо-режим** с виртуальными устройствами,
чтобы можно было посмотреть интерфейс. Подключиться заново — кнопка статуса вверху → «Подключиться».

## Что умеет

- Список устройств с живым предпросмотром каждого светодиода (вентиляторы — кольцом, клавиатура — сеткой).
- Эффекты для любых выбранных устройств сразу: статичный, градиент, дыхание, смена цветов,
  радуга, радужная волна, цветная волна, комета, выключить.
- До 6 цветов в палитре, готовые образцы цветов, скорость, яркость, направление.
- Общая яркость всех устройств одним ползунком.
- Встроенные (аппаратные) режимы устройства — работают даже когда приложение закрыто.
- Профили: сохранить текущую подсветку, загрузить в один клик, профиль при запуске.

Ctrl+клик по устройству — выбрать только его.

## Как устроено

| Файл | Что делает |
|---|---|
| `app.py` | Flask-сервер с REST API и запуск окна (Edge/Chrome в режиме приложения) |
| `rgb_backend.py` | Подключение к OpenRGB SDK и демо-устройства |
| `effects.py` | Программные эффекты, ~30 кадров/с |
| `static/` | Интерфейс |

Настройки и профили хранятся в `%APPDATA%\RGBStudio`.

Программные эффекты работают, пока открыто приложение (как и в самом OpenRGB).
Если нужно, чтобы подсветка сохранялась без него — используйте вкладку «Встроенные режимы».
